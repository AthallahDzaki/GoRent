# GoRent

GoRent adalah sebuah REST API yang dirancang untuk memudahkan proses penyewaan kendaraan secara online. Dengan GoRent, pengguna dapat mencari, memesan, dan mengelola penyewaan kendaraan dengan cepat dan efisien.

## Fitur Utama

- **Pencarian Kendaraan:** Temukan kendaraan yang tersedia berdasarkan lokasi, tipe, dan tanggal sewa.
- **Pemesanan Online:** Lakukan pemesanan kendaraan secara real-time melalui endpoint yang disediakan.
- **Manajemen Penyewaan:** Pantau status penyewaan, riwayat transaksi, dan detail kendaraan.
- **Autentikasi & Otorisasi:** Sistem login dan registrasi untuk keamanan data pengguna.
- **Dokumentasi API:** Endpoint lengkap dengan dokumentasi untuk memudahkan integrasi.

## Teknologi

- **Backend:** ExpressJS (Node.js)
- **Database:** MySQL
- **Autentikasi:** JWT (JSON Web Token)
- **Dokumentasi:** Swagger & Postman

## Cara Penggunaan

1. Clone repository ini.
2. Install dependensi yang diperlukan dengan `npm install`.
3. Jalankan server dengan `npm start` dan akses endpoint sesuai dokumentasi.

## Dokumentasi API

Dokumentasi lengkap tersedia pada endpoint `/docs` setelah server dijalankan.
